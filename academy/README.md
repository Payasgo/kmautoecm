# KMAutos Academy — Milestone 1

Standalone responsive academy landing-page prototype for `learn.kmautoecm.com`.

## Included
- Premium dark KMAutos visual direction using the existing black / white / `#ff3c00` palette.
- Responsive navigation and mobile menu.
- Academy introduction, learning pathways, course previews, lab concept preview, and diagnostic case-study section.
- Uses the existing KMAutos logo hosted on the current website.

## Scope
This milestone is a front-end design prototype only. Student authentication, enrolment, payments, instructor tools, database persistence, and functioning simulations are not implemented. Course cards are marked “Coming soon”.

## Local preview
Open `index.html` in a browser. Internet access is needed for Google Fonts, remote images, and the existing KMAutos logo.

## Separate deployment
Deploy this folder as an independent project (for example, Vercel with `academy/` as the project root), then connect `learn.kmautoecm.com` as its custom domain. The hosting/DNS account owner must add the DNS record requested by the deployment provider.

**Do not change** existing `www.kmautoecm.com` DNS records, the root website, or its CNAME.
